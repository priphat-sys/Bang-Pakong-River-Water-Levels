# การวิเคราะห์ระดับน้ำแม่น้ำบางปะกง

Exploratory Data Analysis on Trend and Distribution of Bang Pakong River Water Levels

โครงงานวิเคราะห์ระดับน้ำแม่น้ำบางปะกง ตั้งแต่ 7 พฤษภาคม 2562 ถึง 23 มิถุนายน 2569
ด้วยสถิติเชิงพรรณนาและแบบจำลอง Random Forest (ข้อมูลทุติยภูมิจากกรมชลประทาน ฉะเชิงเทรา)

## คำถามของโครงงาน

1. ระดับน้ำแปรผันตามฤดูกาลหรือไม่ และเดือนใดสูงสุด/ต่ำสุด
2. การแจกแจงเป็นอย่างไร และมีค่าผิดปกติเท่าใด
3. ระดับน้ำรายปีมีแนวโน้มเพิ่มขึ้นหรือลดลงหรือไม่
4. Random Forest ทำนายระดับน้ำเฉลี่ยรายเดือนได้แม่นเพียงใดเมื่อเทียบกับแบบจำลองพื้นฐาน

## แหล่งข้อมูล

- ชุดข้อมูล: `Clean_BangPaKong.xlsx` เจ้าของข้อมูล กรมชลประทาน ฉะเชิงเทรา
- ลิงก์: https://docs.google.com/spreadsheets/d/17Rhdc_B2VhpVXhngCWWYakU8LTq41nL/edit?usp=sharing
- วันที่ดึงข้อมูล: 23 มิถุนายน 2569
- เงื่อนไขการใช้ (license): ไม่ได้ระบุ ใช้เพื่อการศึกษาและอ้างอิงแหล่งที่มา

## การแบ่งข้อมูลและแบบจำลอง

- รวมเป็นค่าเฉลี่ยรายเดือน 84 เดือน (ไม่รวมกรกฎาคมและสิงหาคม 2564 ที่ไม่มีข้อมูล)
- แบ่งตามลำดับเวลา 80:20 ชุดฝึก 67 เดือน ชุดทดสอบ 17 เดือน (ไม่สุ่มแบ่ง)
- แบบจำลอง: Random Forest ตัวแปรทั้ง 7 (`n_estimators=100`, `random_state=42`) ถดถอยเชิงเส้นด้วยตัวแปรเชิงฤดูกาล
  ค่าเฉลี่ยรายเดือน ค่าเฉลี่ยรวม และ Random Forest เฉพาะ `t` ทุกแบบจำลองฝึกด้วยชุดฝึกเท่านั้น
- เกณฑ์ประเมิน: R², RMSE, MAE (หน่วยเมตร)
